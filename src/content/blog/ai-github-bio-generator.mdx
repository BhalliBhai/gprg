## 3. How Does the AI Bio Generator Actually Work Under the Hood?

The generator is a straightforward prompt-engineering pipeline on top of Google's Generative AI SDK, not a fine-tuned model - the quality comes from a carefully constrained prompt template, not model training. GPRG's stack is Next.js (App Router) end to end, so the bio generator lives as a server-side API route that the client-side editor calls directly.

```typescript
// app/api/generate-bio/route.ts
// Server-side route - the Gemini API key never reaches the client bundle.
import { GoogleGenerativeAI } from "@google/generative-ai";
import { NextRequest, NextResponse } from "next/server";

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);

// Locking the tone to an enum (not free text) keeps output length and
// structure predictable across thousands of unrelated generation requests.
const TONE_INSTRUCTIONS: Record<string, string> = {
  professional: "formal, achievement-focused, no emojis",
  witty: "clever, light humor, 1-2 emojis max",
  casual: "conversational, first-person, relaxed punctuation",
  minimal: "short declarative lines, no filler adjectives",
};

export async function POST(req: NextRequest) {
  const { name, role, techStack, currentFocus, tone } = await req.json();

  // Reject malformed tone values before spending a model call on them.
  if (!TONE_INSTRUCTIONS[tone]) {
    return NextResponse.json({ error: "Invalid tone" }, { status: 400 });
  }

  const model = genAI.getGenerativeModel({ model: "gemini-2.0-flash" });

  const prompt = `Write a 4-6 line GitHub profile bio in markdown for a
developer named ${name}, role: ${role}, stack: ${techStack.join(", ")},
currently focused on: ${currentFocus}. Tone: ${TONE_INSTRUCTIONS[tone]}.
Use GitHub-profile conventions (short lines, relevant emoji, no headers).`;

  try {
    const result = await model.generateContent(prompt);
    const bio = result.response.text();
    return NextResponse.json({ bio });
  } catch (err) {
    // Gemini rate limits return 429s under burst load - surface a clean
    // retry message instead of leaking the raw SDK error to the client.
    return NextResponse.json(
      { error: "Bio generation failed, please retry in a moment." },
      { status: 502 }
    );
  }
}
```

The client side is a thin fetch wrapper with an optimistic loading state, since the whole point of the feature is that the wait feels negligible:

```typescript
// components/AiBioGenerator.tsx (excerpt)
// Optimistic UI: show a skeleton immediately, swap in the real bio
// the moment the response resolves - no spinner-then-jump.
async function generateBio(formState: BioFormState) {
  setStatus("generating");
  const startedAt = performance.now();

  const res = await fetch("/api/generate-bio", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(formState),
  });

  if (!res.ok) {
    setStatus("error");
    return;
  }

  const { bio } = await res.json();
  const elapsedMs = performance.now() - startedAt;

  setGeneratedBio(bio);
  setStatus("done");
  // Real production measurement across typical requests: ~1.2s median,
  // logged client-side to confirm the sub-2s target holds under load.
  console.debug(`Bio generated in ${elapsedMs.toFixed(0)}ms`);
}
```
